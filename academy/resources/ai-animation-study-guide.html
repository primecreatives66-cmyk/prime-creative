AI Animation Bootcamp Offline Study Guide

This guide mirrors the online course structure so students can keep studying when they are offline. Use it with the bootcamp presentation and complete each task before marking the module complete inside the portal.

4 modulesOffline readingProgress tracked in portal

Module 01: Story and Creative Direction

Define the story promise, audience, emotional tone, character, setting and visual direction before generating anything.

  • Write a one-sentence story promise.
  • Define the audience and emotional tone.
  • Create a five-shot plan.

Module 02: Prompt Systems and Consistency

Create reusable prompts for characters, camera, lighting, style and scene motion. Keep identity details consistent across shots.

  • Build a character prompt.
  • Build a location prompt.
  • Write three shot prompts.

Module 03: Image and Video Generation

Generate key frames first, select the strongest frame, then animate with clear motion direction and version notes.

  • Create three key frames.
  • Choose one frame to animate.
  • Save version notes.

Module 04: Edit, Sound and Export

Assemble clips into a finished project with pacing, sound, titles and clean export settings.

  • Edit a 20-40 second animation.
  • Add sound or music.
  • Export and prepare a submission link.
